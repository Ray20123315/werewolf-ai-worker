# 角色覆蓋清單

本檔用來人工檢查角色覆蓋；程式執行時的唯一 canonical source 是 `src/roles.ts`。目前共有 **114** 個 canonical 角色。

硬性原則：任何 Minecraft 暴民式的武器、距離、追逐、移速、碰撞、隱形／裝備互動都不直接搬進 Web 版；角色保留，但能力改寫為資訊、選擇、投票、狀態或結算效果。
